## 📌 Project Overview & Deliverables
This repository contains the complete e-commerce online store implementation and academic business report for **AuraDesk™**:

1. **Working Online Store (`index.html`):**
   - Responsive dark-mode minimalist UI
   - 6 Flagship Products Catalog with high-resolution imagery and specs
   - Category filtering (Stands & Risers, Desk Mats, Accessories)
   - Product quick-view modal with value discrimination specifications
   - Dynamic sliding shopping cart with promo code engine (`AURA15`)
   - Interactive checkout flow simulation

2. **Academic Business Documentation:**
   - **Audience Demand Validation:** Google Keyword Planner empirical data table (177,000+ monthly searches).
   - **Product Differentiation & Price Discrimination:** 2nd-degree bundle discounts and 3rd-degree student pricing.
   - **Financial Economics:** 72.8% Average Gross Profit Margin ($123.80 profit per basket).
   - **Revenue Forecast:** 6-month financial model projecting $96,174 gross revenue; break-even at 29 orders/month.
   - **Omnichannel Marketing Strategy:** 3-stage acquisition funnel (TikTok/Reels, Google PPC, Klaviyo email flows).
